# QuickCut

動画のカッティングと字幕付けに特化したクロスプラットフォーム（Windows / macOS）向け Electron アプリです。マウス操作だけでなく、Enter キーによるスピードカットと Delete キーによる削除に最適化し、字幕のスタイリングもその場で調整できます。

## 特徴
- 貼り付け（Ctrl/Cmd + V）、ドラッグ＆ドロップ、ファイルダイアログの3通りで動画を読み込み
- Enter キーで現在の再生位置にカットポイントを追加、Delete キーで選択中のカットまたは字幕を削除
- 字幕テキストごとに **文字色 / 背景色 / サイズ / フォント** を個別設定し、動画上にオーバーレイ表示
- macOS の Finder からの "開く" や Windows のエクスプローラーからのドロップに対応

## セットアップ
```bash
pnpm install
```
※ ネットワーク環境が必要です。依存関係は Electron 本体に加えて TypeScript / Vitest などの開発ツールです。

## 開発用の起動
```bash
pnpm start
```
TypeScript をビルドしたあと Electron が起動し、`dist/renderer/index.html` が表示されます。ソース編集後は再度 `pnpm start` を実行するか、`pnpm run dev` で `tsc --watch` を回しながら `electron .` を別ターミナルで立ち上げてください。

## テスト (Vitest 古典学派)
```bash
pnpm test
```
Vitest のクラシックランナー（`vitest run`）でユーティリティの単体テストを実行します。

## ビルド
- macOS: `pnpm run package:mac`
- Windows: `pnpm run package:win`
- 両方まとめて: `pnpm run package`

出力バイナリは `dist/` に生成されます（`electron-builder` のデフォルト挙動）。

## 使い方
1. アプリ起動直後の画面で動画を **ドロップ / Ctrl+V で貼り付け / 「動画を開く」ボタンから選択**。
2. 再生ヘッドを移動し、**Enter** でカットポイントを追加。右側のリストから削除したいカットを選び **Delete**。
3. 字幕フォームでテキストと開始・終了秒、スタイル（文字色・背景色・フォント・サイズ）を入力し、登録。
4. 動画再生中は条件に該当する字幕が自動でオーバーレイ表示されます。
5. 字幕リストやカットリストはクリックで選択・編集できます。
